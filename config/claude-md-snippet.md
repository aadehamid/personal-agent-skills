# Writing

Before you write anything a person will read, load the clear-writing skill first and follow it. That covers every reply you send the user, including short ones, plus status updates, emails, docs, READMEs, commit and PR descriptions, posts, and any text the user asks you to edit. It applies to subagents too.

# Working on a repository

Before you change anything in a repository, load the way-of-working skill and follow it. It covers how decisions get recorded, the pull request every change goes through, the checks that run before each push, the independent review that runs before a pull request opens, watching an open pull request until it merges, and the retro that improves the standard.
