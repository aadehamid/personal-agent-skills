# Decision records

Keep decisions that govern this repository here. Keep a consuming project's
decisions in that project. The `way-of-working` skill's
`references/deciding.md` defines the record format and how to preserve the
owner's words.

List each new record below with its date, title, status and path. A proposed
implementation choice is not an approved decision. No convention treating a
skipped question as agreement is recorded here.

No repository decision records have been added to this index yet. Existing
skills' source and change notes remain where their READMEs identify them.
