So basically when the historian stops getting data from the field you'll want to first go check on the collector service which is running on the HIST-COL-02 box, and it's a good idea to look at the logs there (they're in D:\Collector\logs) to see if there's any errors around connection timeouts, which there usually are, and then you can restart the collector service from services.msc, though if that doesn't work it could potentially be the buffer files that got corrupted in which case they need to be cleared out from D:\Collector\buffer and the service restarted again. Also you should check that the data is flowing again in the historian trend after about 5 minutes or so. Oh and one important thing to note is that clearing the buffer means any data that was buffered and not yet sent gets lost permanently, so you should probably export the buffer first using the bufutil export command if the outage has been longer than an hour since that data can't be recovered from the field devices after the RTU's 60 minute local storage rolls over.
