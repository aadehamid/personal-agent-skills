# unslop (alias)

On this machine, clear-writing replaces unslop. Load the clear-writing skill and follow it:

- Text that already exists (a draft, a PR body, a reply you wrote): use clear-writing's Edit mode, ending with its final check against `references/ai-tells.md`.
- Text you are about to write: use clear-writing's Write mode.

A citation such as "unslop rule 14" refers to the same number in clear-writing's `references/ai-tells.md`, which keeps unslop's numbering.
